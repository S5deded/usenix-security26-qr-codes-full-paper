# usenix-security26-qr-codes-full-paper
Full version of USENIX Security '26 Paper: Shielding QR Codes: Unveiling the Real-World Illicit Promotion Behind Adversarial QR Code

---

## Overview

This repository hosts the **full version** of the paper accepted at USENIX Security '26, including the complete appendix and supplementary material. The official conference version (without appendix) is available through the USENIX proceedings.

> **Note:** The conference version submitted to USENIX Security '26 omits the appendix due to the 20-page limit. This repository provides the complete paper, including all appendices, for reference.
